Input Padding
Without input padding, width and 
height of the feature map shrinks at 
each layer
▪ Padding can be applied using either 
zeros or by extending edge values. 
Common choices include
▪ None – width/height shrink
▪ Same – width/height constant
▪ Full – width/height grow
Edge cases must be handled in 
computation
