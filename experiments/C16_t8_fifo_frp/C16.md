Require E017 exactness on all13 images and both changed-parameter RTL transactions; measure whether FIFO and FRP benefits overlap before routing. User requested implementation only after C15 has a recorded result. Use one heavy task with budgeted light work. Runtime srcnn signature, source weights, quantization, original tests and physical gates stay fixed.
