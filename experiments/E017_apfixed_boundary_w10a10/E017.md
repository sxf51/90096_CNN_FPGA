# E017: apfixed_boundary_w10a10

## 1. Purpose and hypothesis / 目的与假设

Cross-check full-image numpy predictions using actual ap_fixed loading and layer-boundary rounding/saturation with exact integer accumulation.

## 2. Changes / 改动

Independent integer-carrier reference. Original all-ap_fixed E014/E012/E013 remain independent and unchanged. Accumulator fractional points and cast modes are identical; int64 carries exact raw sums whose analytical bound is below the 23-bit reference accumulator range. Source commit: `bece7ccf647c9625fd6661c974f7f017ee8a8aef`.
