# F22: continuous_ieee_T16_3ns

## 1. Purpose and hypothesis / 目的与假设

F20 exhausts all signed ten-bit output values across three orderings with exact binary32 equality and measures zero DSP, 242 LUT, 52 FF and 2.051ns. F13's output writer uses three DSP and the 3.239ns sitofp critical path. Replace only raw-to-float output encoding with the proven sign/exponent/significand construction, retain online replicate padding and Conv3 rotation, and test a faster target clock. Every butterfly output bit must retain the first-phase precision reference; no precision or weight-contract change.

## 6. Interpretation / 解读

Compare achieved II, each module's clock and top resource counts against F13. The output converter may cease to be the critical path; memory/address, carried addition or input casts may then dominate. Record any over20percent estimate deviation from parsed reports. Two-frame equality precedes synthesis eligibility.

Continuous scheduling separates window generation and MAC folds, shifts channel registers and explicitly registers fabric reduction trees. This can remove pixel fill/drain but costs pipeline registers and wide window FIFOs. Online padding overlaps source reads with padded writes; old row serialization can create finite-FIFO stalls absent from maximum-component HLS estimates. RTL cycles and routed slack remain the final evidence.
