## 6. Interpretation / 解读

All four RTL output transactions pass the generated C post-check: butterfly and ignored-pointer lenna match E065 exactly, and reloaded/retained constructed parameters produce104/256 everywhere. This functional result is separate from the strict interface verdict. The read-only observer records8129AR requests/8129R beats/32516bytes for each loaded call, but1AR request/1R beat/4bytes for each skipped call. Both skipped calls also have one ARVALID and one RVALID cycle. All parameter writes are zero. The zero-parameter-AXI gate fails, so C27 remains fail and cannot supply an accepted IP frame time or authorize C23 implementation.

The HLS top scalarized biases3[0] into biases3_0_0_val and read it unconditionally before entering the guarded DATAFLOW region. That explains the exact4byte residue without changing the arithmetic or persistent-bank behavior. The source-level C checks could not detect an RTL read which is ignored numerically.

Raw per-transaction performance reports show loaded300634cycles/300666interval and skipped296117cycles/296149interval. Loading is14.2704 percent above the263090-cycle HLS paper estimate because finite-FIFO and AXI scheduling are absent from the static component bound. Skipping saves4517cycles, or1.50249 percent of a loaded call, but this is failed-run diagnostic evidence rather than accepted WS-F performance. No DSP, memory or physical clock is measured by this run.

The original runner loaded modules before failure-retention recovery was added.
