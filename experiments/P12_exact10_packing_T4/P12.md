# P12: exact10_packing_T4

## 1. Purpose and hypothesis / 目的与假设

Integrate the measured exact10 residual PE. Conv1/Conv2 pair output channels sharing each input. Conv3 pairs adjacent outputs sharing each weight, centers the upper nonnegative activation by256, repairs signed-low borrowing, then restores both coefficient residuals. Decode every product, so no low-field accumulation bound is assumed. Preserve all first-phase quantization points.

## 6. Interpretation / 解读

Compare DSP halving to residual/borrow LUT cost and pixel scheduling. Preserve any resource excess; exact10 is chosen because uniform INT8 loses5.18dB.

Two products share one DSP only when operand packing and signed-low borrowing are handled explicitly. Exact ten-bit coefficient residuals add fabric control/adders, and adjacent-pixel Conv3 needs a5x6 window plus odd-column disposal. Extra multiplier/pipeline depth is paid on every pixel in nested fold schedules. PE cycle counts cannot be interpreted as network-frame times.
