# E030: dataflow_float

## 1. Purpose and hypothesis / 目的与假设

Prove float replicate-padding streaming flow matches untouched golden before fixed-point synthesis.

## 2. Changes / 改动

read_input -> pad1 -> nested conv12 (separate overlapping Conv1/Conv2 engines) -> pad3 -> gather Conv3 -> write_output. Runtime weights load into on-chip arrays before the DATAFLOW region; external signature unchanged. Source commit: `6d13dcde76f6c4c4b373663a6d6178537ffc7011`.
