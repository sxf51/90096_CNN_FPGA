# E047: dataflow_dsp_T32

## 1. Purpose and hypothesis / 目的与假设

Force the 251 direct-convolution products per cycle onto DSPs. E033 default narrow multiplication used only 9 DSP but 136,868 LUT, exceeding the 81,984 LUT limit. Expected MAC DSP split 162/64/25 plus conversion/interface overhead; compute floor 2,080,800 cycles.

## 2. Changes / 改动

Independent copy of E046 no-overflow design. Every fully-unrolled product is an explicit local variable bound to op=mul, impl=dsp. Source commit: `af351bab36dcd4f95babc0f427342112b6c36bf2`.
