# F53: legacy_C13_regression

## 1. Purpose and hypothesis / 目的与假设

WS-F: gate runtime parameter reading/transformation/private-bank loading inside unconditionally called DATAFLOW processes. Retain the original srcnn wrapper with load=true and add srcnn_reload with a control load_params bit. Force the first call to load even when its flag isfalse; skipped calls must ignore all incoming parameter pointers and reuse the most recent persistent banks. Require unchanged E065 exact arithmetic, six-pixel border checking and13-image deltaPSNR>=-0.1dB. Validation mode: regression.
