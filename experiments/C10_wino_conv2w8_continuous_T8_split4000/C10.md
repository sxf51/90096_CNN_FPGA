# C10: wino_conv2w8_continuous_T8_split4000

## 1. Purpose and hypothesis / 目的与假设

W11 C simulation passes exactly but synthesis rejects the8000-bit aggregated Conv3 stream with HLS214-256: maximum4096 bits. Preserve the continuous schedule and represent one800-element window as two25x16-channel4000-bit packets, each below the measured limit. Both streams produce/consume65025 packets per frame; no quantization or MAC change. E065 independently verifies Conv2-only signed8 weights/bias at the mixed precision point with13-image deltaPSNR=-0.07589037644656216dB. Pair those coefficients with shared ten-bit activations in one27x10 DSP product, with borrow correction but no coefficient residual restoration. Combine continuous integer Winograd Conv1 and direct Conv3; this avoids the failed uniformINT8 gate and full exact10 packing's large residual fabric cost.

New independent source based on C08. Replace the single oversized window stream with two synchronized channel halves. Each uses a two-entry LUTRAM FIFO; compute retains the complete window and chooses the correct half for each input channel. All first-phase and attempted sources stay frozen.
