The independent W21 implementation closes its actual 5 ns constraint: WNS +0.140 ns, TNS 0, WHS +0.020 ns, TPWS 0, and no unrouted nets. F97 measured 558,758 RTL cycles, so the IP frame time at this closed target is 2.79379 ms. The slack-derived 4.86 ns period has not been implemented or validated and is not an accepted operating point. No board measurement is inferred.

DSP matches the paper/HLS estimate exactly (644). Routed LUT is 42,594 versus 81,086 estimated (-47.47%); FF is 88,806 versus 130,057 (-31.72%); BRAM18K-equivalent is 109 versus 146 (-25.34%). These deviations exceed 20% because HLS operator/storage estimates precede Vivado optimization, LUT combining and physical memory packing; the physical hierarchy and primitive reports preserve the actual evidence. The memory report contains 46 RAMB36E2 and 17 RAMB18E2, not 54.5 physical RAMB36 primitives. Continue to apply the original HLS resource gates. RTL latency is 6.382071% above the 525,237-cycle HLS estimate; F97's finite-FIFO and AXI profile explains overlapping waits, which must not be summed as independent frame penalties.

Three of the five setup paths run from the Conv2 parameter FIFO data register to private weight LUTRAM write data, with zero logic levels. The worst path has 4.704 ns data delay, of which 4.591 ns (97.598%) is routing, and a fanout of 257. The other two paths run from the Conv3 step register through three LUT levels into one DSP input, with 4.318/4.297 ns data delay. None uses a DSP PCIN/PCOUT cascade. This limits further clock improvement through physical distribution of parameter data and control, rather than multiplier arithmetic alone. F95's Conv1 write-address path is a different RTL result and is not evidence for this design.
