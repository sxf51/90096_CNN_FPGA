# F04: continuous_T16_online_4ns

## 1. Purpose and hypothesis / 目的与假设

Separate window production from convolution engines, flatten pixel/fold loops into oneII1 loop and shift fixed channel registers each fold. Register balanced fabric reductions to break E070's eight-DSP unregistered adder path. Online padding caches the first row and reads/emits subsequent rows together, avoiding pad3's serialized row phases.
