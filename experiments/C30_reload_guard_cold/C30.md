# C30: reload_guard_cold

## 1. Purpose and hypothesis / 目的与假设

Repair C27's observed4byte skipped-call parameter read in an independent C23-derived design. HLS scalarizes biases3[0] and hoists its read into the top before the inner do_load guard. Explicitly capture the scalar through a const volatile pointer only in the non-DATAFLOW top do_load branch,then pass the value internally. Preserve the nine-argument reload top,the compatible original wrapper,all arithmetic,parameter counts,FIFO depths,loaded-state semantics,E065 precision and strict zero parameter AR/R/AW/W activity on skipped calls. Validation mode: cold.
