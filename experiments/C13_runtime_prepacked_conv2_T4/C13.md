# C13: runtime_prepacked_conv2_T4

## 1. Purpose and hypothesis / 目的与假设

WS-E early HLS screening while mainline clock/FIFO RTL controls run. Use an independent runtime-loaded W21 clone atT4; keep Winograd Conv1 and direct Conv3 exact10-bit, replace only Conv2 with E065's independently validated signed8-bit weights/bias and21-bit accumulator. Pack each coefficient pair once during its private parameter load, removing packing arithmetic from every pixel. Unpack each37-bit27x10 product separately with signed-low borrow repair. This is precision-exact against E065, not the uniform10-bit E017. No route launch until DSP<=1100 and LUT<=170k and memory admission permits it.

## 6. Interpretation / 解读

All13 course images match E065's mixed-precision reference bit for bit; mean deltaPSNR=-0.07589037644656216dB and six-pixel butterfly borderMSE=1.405191888267716e-05. This is exact packing of the independently accepted Conv2-w8 precision, not equivalence to uniform10-bit E017. Each pair multiplies two signed8 coefficients by one10-bit activation and repairs signed-low borrowing before any pair accumulation, so no multi-product low-field overflow is introduced.

Measured layerDSPs are576/256/200, exactly the1032 paper budget. TotalBRAM18K146 matches;127966LUT/192308FF are14.69%/12.59% below150000/220000 estimates. The263090-cycle HLS component bound is9.90% below the292000 paper RTL hypothesis, but finite-FIFO cycles remain unmeasured. Every total deviation is within20%. Compared with old C11, LUT falls from198436 to127966 and FF from231297 to192308; the independent new design changes runtime-private loading/prepacking and uses4ns HLS scheduling, so this is a whole-design comparison rather than attribution of the entire difference to packing alone.

Conv2's report assigns37074LUT/80091FF/256DSP; its continuous fold alone costs27637LUT/64389FF. Prepacking moves coefficient concatenation into a once-per-frame2192-cycle load, but reduction, per-product borrow repair and captured operands still consume substantial fabric/registers. Conv1 engine costs38414LUT/41307FF/576DSP and Conv3 engine23676LUT/36001FF/200DSP. II1 is achieved in all three folds. The legacy HLS70% gate labels the row infeasible; under docs/0005's final routed policy it nevertheless passes the explicit DSP<=1100/LUT<=170k/FF<=230k implementation screen. Neither label establishes actual resource feasibility or a4ns closed clock.
