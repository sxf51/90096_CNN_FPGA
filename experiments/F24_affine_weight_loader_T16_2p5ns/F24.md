# F24: affine_weight_loader_T16_2p5ns

## 1. Purpose and hypothesis / 目的与假设

F23 reports a2.822ns15-bit address mul in srcnn_Pipeline_load1 at the flattened Conv1 weight read; its dataflow_region is2.377ns and write_output is1.825ns. The one-time loader therefore controls the global HLS clock estimate despite unchanged T16 inference engines. Replace the division/modulo-derived Conv1 index with explicit channel/kernel-row/kernel-column counters. Keep the runtime float parameters, every quantization point, memory partitions, streams, padding and MAC schedule. Hypothesis: remove the magic-division address multiplier and approach the2.5ns target without altering output bits.
