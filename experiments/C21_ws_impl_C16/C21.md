## 6. Interpretation / 解读

C21 independently closes 4.5 ns with WNS +0.053 ns, WHS +0.029 ns, zero TNS/THS and no unrouted or partially routed nets. All routed resource gates pass: 644 DSP, 54,139 LUT, 78,445 FF and 109 BRAM18K. Matching C19 verifies both changed-parameter RTL calls at 535,976 cycles (interval 536,005), so the accepted IP frame product is 2.411892 ms. This improves W30's 2.472471 ms by 2.45 percent, but C22 remains faster at 1.365115 ms. These are IP results with ideal simulated AXI; no board or DDR timing is measured.

The committed paper resource estimates used frozen C16 HLS counts. DSP remains exactly 644; routed LUT, FF and BRAM18K are respectively 33.56, 39.71 and 25.34 percent below those estimates. The independently generated hierarchical utilization reports show the optimized physical mapping, while HLS counts scheduled operators, temporary storage and estimated memory banks. Therefore these differences reflect physical optimization and storage packing rather than a change in arithmetic or precision. The measured RTL cycle count is 2.04 percent above the 525,237-cycle HLS component bound, consistent with remaining finite-FIFO and interface stalls.

All five exported setup paths terminate in private weight-memory data or address inputs. The worst path starts in the Conv3 parameter FIFO and reaches its local weight RAM with zero reported combinational logic levels and 4.295 ns data-path delay. The next two paths traverse Conv2/Conv3 parameter FIFOs; the last two traverse the Conv1 local-loader address register. Thus the present 4.5 ns limit is parameter distribution and local-memory routing. No exported path traverses DSP cascade PCIN/PCOUT. The 53 ps setup margin does not justify claiming an untested faster clock.
