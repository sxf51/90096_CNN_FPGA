FRP profiling shows no read-block cycles for features_U, windows_U or either Conv3 windows stream, versus46990,45974 and54556 respectively in F97. The FRP pipeline also has peak features2 depth20 and operand-window depth5, so style changes include extra buffering and change timing behavior; counters overlap and cannot be summed into9320 saved cycles. A future FRP throughput experiment needs a new predeclared acceptance criterion and independent routing. The current experiment proves exact finite-FIFO operation but does not establish a verified routed frame time or board latency.

User revision on2026-10-12 explicitly removes the lower cycle bound because the goal was to prevent slowdown. An acceptance_override records that authorization; original status=fail, error, report and paper plan remain unchanged. W30 is now authorized to implement frozen W27 at4.5ns.
