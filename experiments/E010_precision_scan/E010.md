# E010: precision scan

## 1. Purpose and hypothesis / 目的与假设

Find low-precision settings retaining mean PSNR within 0.1 dB of float golden, and determine integer ranges using all supplied images. Exact integer sums permit reorder-invariant architecture checks. No HLS performance prediction is made by this software-only experiment.

## 2. Changes / 改动

New profiling bridge and numpy fake-quant model. Source commit `1f025dccb9e5fb187213ff4aea10887e617ab078`; protected original sources are included unchanged in an independent comparison.
