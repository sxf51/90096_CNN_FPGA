# S04: tile_fusion_B16

## 1. Purpose and hypothesis / 目的与假设

Explore B=16 output-tile fusion. Cache(B+12)^2 input values and(B+4)^2 Conv2 features, fusing Conv1/Conv2 per feature center. Clamp each feature center to the true image before selecting its9x9 input patch, preserving replicate at Conv3. Partial edge blocks still schedule complete feature halos; unused output cells are skipped.

## 2. Changes / 改动

Independent tile engine, no DATAFLOW between tiles/layers. Same exact fixed-point arithmetic and original float-array interface; on-chip input and feature2 caches use spatial banks.
