# E050: scatter_T32

## 1. Purpose and hypothesis / 目的与假设

Compare gather with channel-reduced scatter using 5x255x32-bit partial sums and a 5x5 register window. The register window should avoid five simultaneous read-modify-write accesses per physical BRAM bank. Ideal Conv3 budget 25 DSP at T32; padding adds 3.16% Conv3 input work.

## 2. Changes / 改动

Independent copy of dataflow_v1. Conv1/Conv2 and interfaces unchanged; Conv3 uses scatter, one read/write per fixed physical cache bank and five-column register reuse. Explicit pad3 retained. Source commit: `f5990c904b80dc8aac23150897e5eda2375ba798`.
