# E057: integer_lutram_T32

## 1. Purpose and hypothesis / 目的与假设

Banked writable LUTRAM with T=32. Ideal DSP 251, compute floor 2080800 cycles. Gather buffer control 168 BRAM18K. Banked weight storage should remove E047's large register write/read muxes.

## 2. Changes / 改动

E048 exact integer-carrier design; only T and weight storage parameter change. Source commit: `2eb2ea43fc8b50176c8c2558d6cb59976ade68e2`.
