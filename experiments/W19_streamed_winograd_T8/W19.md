# W19: streamed_winograd_T8

## 1. Purpose and hypothesis / 目的与假设

After strict WS2 loader selection, integrate its stream-owned parameter loading into independent W17 Winograd T8. Preserve exact integer G2 transforms, nine3x3 subkernels, two-row tile reorder and layer quantization; explicitly enable online replicate padding and exact IEEE output encoding. Test whether reducing duplicated conversion/top ownership overhead makes the unchanged Winograd compute schedule HLS-resource feasible. This advance paper plan is conditional: implementation/execution waits for the measured F28 loader conclusion, and missed WS2 gates cannot be called accepted.

## 2. Changes / 改动

Independent W17 copy. Replace top raw/transformed banks and load loops with nested parameter DATAFLOW: one read_raw_params converter, a single-channel81-coefficient transform buffer, and three distinct layer streams. Conv1 packets contain16 exact14-bit transformed fields (224bits),640 packets total including64 bias packets. Consumers load private simple-dual-port LUTRAM banks before pixels; inherit the measured-selected local-load flatten policy. Conv2/Conv3 compute and Winograd tile/window/reorder loops remain W17's. Use the frozen F25/F28 exact IEEE decode header. No parent design or interface change. Source commit: `7be52961ca1b0ed0b783afb3109d5de80d4d1ff6`.
