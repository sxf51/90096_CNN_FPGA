## 2. Changes / 改动

Independent W17 copy. Replace top raw/transformed banks and load loops with nested parameter DATAFLOW: one read_raw_params converter, a single-channel81-coefficient transform buffer, and three distinct layer streams. Conv1 packets contain16 exact14-bit transformed fields (224bits),640 packets total including64 bias packets. Consumers load private simple-dual-port LUTRAM banks before pixels; inherit the measured-selected local-load flatten policy. Conv2/Conv3 compute and Winograd tile/window/reorder loops remain W17's. Use the frozen F25/F28 exact IEEE decode header. No parent design or interface change.
