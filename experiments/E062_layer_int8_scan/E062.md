# E062: layer-specific INT8 precision

## 1. Purpose and hypothesis / 目的与假设

Check whether a single INT8 layer can retain the 0.1 dB quality gate even though uniform INT8 fails. Software-only study; no DSP or latency claim.

## 2. Changes / 改动

Generalized layer widths with the unchanged E010 integer-fraction semantics; independently compiled unchanged golden. Source commit `de1138d1c31b2e8933cef2420711c9ea1baf3bcd`.

## 6. Interpretation / 解读

Each point includes every supplied image and retains full fractions without accumulator overflow. An accepted fake-quant point still needs actual ap_fixed confirmation before hardware integration. Missing comic prevents full Set14 acceptance.

## 7. Conclusion and next step / 结论与下一步

Use measured layer eligibility to constrain phase-two packing. If no genuine INT8 layer passes, exact integer decomposition can preserve w10 precision.
