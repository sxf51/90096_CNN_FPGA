# E063: dataflow_wrap_T32_retry

## 1. Purpose and hypothesis / 目的与假设

Remove redundant saturation logic from exact fractional accumulators. The E010 analytical absolute-sum bounds fit integer bits 6/6/7 for the protected trained weights and every representable activation. Ideal budget 251 DSP, 2,080,800 compute cycles, unchanged buffers.

## 2. Changes / 改动

Independent dataflow_v1 copy; only accumulator overflow/rounding modes change to AP_WRAP/AP_TRN. Input, weight, bias and layer-output casts retain AP_RND_CONV/AP_SAT. Products have full fractional precision. Retry of E046: Separate synthesis queue wait from the unchanged 60-minute process timeout. Source commit: `6d7039b83f39b75f9b752a1b650b2e441b4180f3`.
